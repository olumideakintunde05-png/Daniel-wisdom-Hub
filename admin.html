Send a push notification
Push notifications go through OneSignal (already wired into your app for both Android and iOS). Sending safely requires your OneSignal API key, which should never sit in this page's code since anyone could view it. Use the OneSignal dashboard directly — it's built exactly for this, no extra coding needed.
